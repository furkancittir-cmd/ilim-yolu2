# İlim Yolu

Bu klasör, Vite + React başlangıç projesidir.

## Çalıştırma
```bash
npm install
npm run dev
```

## Yayınlama
- Bu projeyi GitHub'a yükle
- Vercel'de "New Project" ile repo'yu bağla
- Deploy de

## Not
Canvas'taki güncel `App.jsx` kodunu istersen bu projedeki `src/App.jsx` dosyasına yapıştır.
